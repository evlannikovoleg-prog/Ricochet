Сервис «Рикошет» развивает два направления: поиск скрытых зависимостей аварий
и предпроверку инцидентов. Данные — публичный датасет [AIOps Challenge 2020](https://github.com/NetManAIOps/AIOps-Challenge-2020-Data)
(реальная китайская платформа: бизнес-метрики ESB + платформенные метрики + трейсы,
15 дней наблюдений, список отказов как ground truth). Китайские пути и имена
переименованы в английские на стороне ингеста; оригинальный архив не изменяется.

## Направления

1. **«Эффект бабочки»** — скрытые зависимости без корреляционных правил.
   Вход: поток аварий (время, узел, регион, система, тип события). Выход: граф
   недокументированных межсистемных зависимостей — кандидаты в новые корреляционные правила.
   Контроли против ложных связей от общего предка: снятие общего фактора,
   стратификация по времени суток, фильтр «вечно горящих» рядов, отсев хабов,
   отсев одиночных объектов, устойчивость по суткам, повторяемость по регионам,
   holdout по месяцам, исключение окон обслуживания.

2. **Предпроверка перед существующим ИИ-агентом**. Отрабатывает раньше агента,
   со стороны мониторинга, и собирает «дело»: кандидат-первопричина из скрытых
   зависимостей, похожие исторические инциденты, полнота обогащения, окно
   обслуживания, предлагаемый runbook и риск-флаги. Точка подключения — хук в
   тикетинг-политике или сервис, слушающий новые инциденты.

## Быстрый старт

```powershell
# зависимости
pip install -r requirements.txt

# (вариант А) синтетический поток с посаженными паттернами — для демо и тестов
python scripts\make_synthetic_data.py

# (вариант Б) реальный датасет AIOps Challenge 2020
# 1) скачать AIOps挑战赛2020预赛数据.zip -> data\raw\aiops2020.zip
#    (Google Drive / Tsinghua Cloud, md5 fac7fe1b4e048c81ef88874334b73534)
# 2) распаковка с переименованием в английские пути:
python scripts\ingest_aiops2020.py --mode extract
# 3) конвертация метрик/трейсов в аварии канонической схемы:
python scripts\ingest_aiops2020.py --mode ingest

# тесты
python -m pytest tests -q

# запуск API
.\run_api.ps1   # uvicorn, http://127.0.0.1:8077
```

Если `data\processed\alarms.parquet` отсутствует, API при старте генерирует
синтетический поток (45 дней) — сервис поднимается без датасета.

## Структура

```
src/ricochet/
  canonical.py       каноническая схема алармов (аналог REPORTER_STATUS)
  leadlag.py         движок: биннинг, lag-корреляции, фильтры, устойчивость
  verdicts.py        вердикты: дубль / бабочка (общие vs несовпадающие устройства)
  maintenance.py     окна обслуживания
  ingest/aiops2020.py  адаптер датасета (китайский -> английский -> аварии)
  ingest/synthetic.py генератор синтетики с посаженными паттернами
  precheck/          сборка «дела» для ИИ-агента
  api/               FastAPI: /butterfly/*, /precheck/*, /maintenance/*
docs/                API.md, DATA_MAPPING.md, METHOD_BUTTERFLY.md
tests/               pytest: движок, предпроверка, API
```

## Каноническая схема аларма

| поле | аналог Netcool | источник в AIOps 2020 |
|---|---|---|
| `ts` | `AggregationFirst` | `timestamp`/`startTime` (epoch ms → UTC) |
| `integration` | `IntegrationName` | слой: `platform` / `business` / `trace` |
| `system` | `Agent` | источник: `os_linux`, `db_oracle_11g`, `esb`, имя сервиса |
| `alert_group` | `AlertGroup` | метрика+направление (`CPU_free_pct_low`) или `CSF_fail` |
| `node` / `node_alias` | `Node` / `NodeAlias` | `cmdb_id` (оба поля — из словаря устройств) |
| `region` | `Tp1SuperRegion` | в датасете нет → `""` |
| `severity` | `OriginalSeverity` | 3–4 |
